# ସମ୍ବଲପୁରୀ ଶାଢ଼ୀ — ସୂତାରେ ବୁଣା କଳା

**ସମ୍ବଲପୁରୀ ଶାଢ଼ୀ** ହେଉଛି ଭାରତର ସର୍ବୋତ୍ତମ ହସ୍ତତନ୍ତ ବସ୍ତ୍ର ମଧ୍ୟରୁ ଅନ୍ୟତମ, ଯାହାର ଉତ୍ପତ୍ତି ଓଡ଼ିଶାର ପଶ୍ଚିମ ଜିଲ୍ଲାଗୁଡ଼ିକରୁ ହୋଇଛି। ଏହାର ସ୍ୱତନ୍ତ୍ର **ଇକତ (ବାନ୍ଧ)** କୌଶଳ ପାଇଁ ଜଣାଶୁଣା ଯେଉଁଥିରେ ଲୁଗା ବୁଣିବା ପୂର୍ବରୁ ସୂତାକୁ ରଙ୍ଗରେ ବନ୍ଧା ଯାଇଥାଏ, ପ୍ରତ୍ୟେକ ଶାଢ଼ୀ ହେଉଛି ଏକ ମାଷ୍ଟରପିସ୍ ଯାହାକୁ ତିଆରି କରିବା ପାଇଁ **୨ ରୁ ୪ ସପ୍ତାହ** ଲାଗିଥାଏ।

## ସଂକ୍ଷିପ୍ତ ତଥ୍ୟ

| ପ୍ରସଙ୍ଗ | ବିବରଣୀ |
|--------|---------|
| **ଉତ୍ପତ୍ତି** | ସମ୍ବଲପୁର, ବରଗଡ଼, ସୋନପୁର, ବୌଦ୍ଧ ଜିଲ୍ଲା |
| **ଜିଆଇ (GI) ଟ୍ୟାଗ୍** | ୨୦୦୫ ରେ ପ୍ରଦାନ କରାଯାଇଛି |
| **କୌଶଳ** | ଇକତ (ବାନ୍ଧ) — ବୁଣିବା ପୂର୍ବରୁ ଟାଇ-ଡାଏ |
| **ସାମଗ୍ରୀ** | ରେଶମ ଏବଂ ସୂତା (କଟନ) |
| **ୟୁନେସ୍କୋ (UNESCO)** | ଅମୂର୍ତ୍ତ ସାଂସ୍କୃତିକ ଐତିହ୍ୟ ତାଲିକାରେ ଅନ୍ତର୍ଭୁକ୍ତ |

## ବାନ୍ଧ କୌଶଳ

ସମ୍ବଲପୁରୀ ବସ୍ତ୍ରର ଯାଦୁ **ବାନ୍ଧ**ରେ ରହିଛି, ଯାହାର ଅର୍ଥ "ବାନ୍ଧିବା":

୧. **ଡିଜାଇନ୍ ଯୋଜନା** — ଗ୍ରାଫ୍ ପେପରରେ ପ୍ୟାଟର୍ଣ୍ଣ ମ୍ୟାପ୍ କରାଯାଏ
୨. **ବାନ୍ଧିବା** — ସୂତା ଗୁଡ଼ିକୁ ଏକାଠି କରି ମହମ ଲଗା ସୂତାରେ ନିର୍ଦ୍ଦିଷ୍ଟ ବିନ୍ଦୁରେ ବନ୍ଧାଯାଏ
୩. **ରଙ୍ଗ ଦେବା** — ବନ୍ଧା ହୋଇଥିବା ଅଂଶ ରଙ୍ଗକୁ ପ୍ରତିରୋଧ କରେ, ଯାହା ଦ୍ୱାରା ଡିଜାଇନ୍ ସୃଷ୍ଟି ହୁଏ
୪. **ବୁଣିବା** — ରଙ୍ଗୀନ ସୂତାକୁ ଲୁଗାକଳ (ତନ୍ତ) ରେ ଯତ୍ନର ସହ ସଜାଯାଏ
୫. **ଚୂଡ଼ାନ୍ତ ଉତ୍ପାଦ** — ପ୍ୟାଟର୍ଣ୍ଣଗୁଡ଼ିକ ବସ୍ତ୍ରରେ ପ୍ରାକୃତିକ ଭାବରେ ବୁଣା ହୋଇଥିବା ଦେଖାଯାଏ

> "ବାନ୍ଧ ବୁଣିବାରେ, ଡିଜାଇନ୍ ସୂତାରେ ଜନ୍ମ ହୁଏ, ତନ୍ତରେ ନୁହେଁ — ଯାହା ପ୍ରତ୍ୟେକ ଶାଢ଼ୀକୁ ଏକ ପୂର୍ବ-ନିର୍ଦ୍ଧାରିତ ଚମତ୍କାର କରିଥାଏ।"

## ପ୍ରମୁଖ ଡିଜାଇନ୍ (Motifs)

ସମ୍ବଲପୁରୀ ଶାଢ଼ୀରେ ପ୍ରକୃତି ଏବଂ ମନ୍ଦିର ସ୍ଥାପତ୍ୟ ଦ୍ୱାରା ଅନୁପ୍ରାଣିତ ଡିଜାଇନ୍ ରହିଥାଏ:

| ଡିଜାଇନ୍ | ଅର୍ଥ |
|-------|---------|
| **ଶଙ୍ଖ** | ଶୁଭର ପ୍ରତୀକ |
| **ଚକ୍ର** | ପ୍ରଭୁ ଜଗନ୍ନାଥଙ୍କ ଚକ୍ର |
| **ଫୁଲ** | ପ୍ରକୃତିର ସୌନ୍ଦର୍ଜ୍ୟ |
| **ହାତୀ** | ଗାମ୍ଭୀର୍ଯ୍ୟ |
| **ମୟୂର** | ଅନୁଗ୍ରହ ଏବଂ ସୌନ୍ଦର୍ଯ୍ୟ |
| **ମତ୍ସ୍ୟ** | ଉର୍ବରତା |

## ସମ୍ବଲପୁରୀ ବସ୍ତ୍ରର ପ୍ରକାରଭେଦ

### ସମ୍ବଲପୁରୀ ରେଶମ (ସିଲ୍କ) ଶାଢ଼ୀ
ମୁଖ୍ୟ ଉତ୍ପାଦ — ଜଟିଳ ବାନ୍ଧ କାମ ସହିତ ସମୃଦ୍ଧ ରେଶମ, ଯାହା ବିବାହ ଏବଂ ଉତ୍ସବରେ ପିନ୍ଧାଯାଏ।

### ବୋମକେଇ ଶାଢ଼ୀ
ଗଞ୍ଜାମ ଜିଲ୍ଲାର **ବୋମକେଇ** ଗାଁରୁ:
- ଏମ୍ବ୍ରୋଡେରୀ କରାଯାଇଥିବା ଧଡ଼ି (ବର୍ଡର) ପାଇଁ ଅତିରିକ୍ତ ୱେଫ୍ଟ କୌଶଳ
- ମନ୍ଦିର-ଅନୁପ୍ରାଣିତ ପ୍ୟାଟର୍ଣ୍ଣ ସହିତ ସମୃଦ୍ଧ ପଲ୍ଲୁ (ଅଞ୍ଚଳ)
- ପ୍ରାୟତଃ "ସୋନପୁରୀ" ଶାଢ଼ୀ ଭାବରେ କୁହାଯାଏ

### ହାବସପୁରୀ ଶାଢ଼ୀ
କଳାହାଣ୍ଡିର **ହାବସପୁର** ଗାଁରୁ:
- ମାଛ ଲାଞ୍ଜ ଧଡ଼ି ଡିଜାଇନ୍ (ସ୍ୱତନ୍ତ୍ର ପରିଚୟ)
- ସରଳ ତଥାପି ଆକର୍ଷଣୀୟ ଡିଜାଇନ୍
- ରେଶମ ଧଡ଼ି ସହିତ ମୁଖ୍ୟତଃ ସୂତା (କଟନ)

### ପାସାପାଲି
- **ଚେସ୍ ବୋର୍ଡ ପ୍ୟାଟର୍ଣ୍ଣ** (ପାସା = ଲୁଡୁ ବା ଛକା)
- ଆକର୍ଷଣୀୟ ବିକଳ୍ପ ରଙ୍ଗର ବର୍ଗାକାର
- ଦୈନନ୍ଦିନ ପିନ୍ଧିବା ପାଇଁ ଲୋକପ୍ରିୟ

### ବାପ୍ତା ଶାଢ଼ୀ
- ରେଶମ ଏବଂ ସୂତାର ମିଶ୍ରଣ
- ହାଲୁକା ଏବଂ ଅଧିକ ସୁଲଭ
- ଦୈନନ୍ଦିନ ବ୍ୟବହାର ପାଇଁ ଉପଯୁକ୍ତ

## ବୁଣାକାର ସମ୍ପ୍ରଦାୟ

**ମେହେର** ସମ୍ପ୍ରଦାୟ ହେଉଛନ୍ତି ପାରମ୍ପରିକ ରକ୍ଷକ:
- ବୁଣିବା ହେଉଛି ଏକ **ପାରିବାରିକ କଳା** — ପିଢ଼ି ପରେ ପିଢ଼ି ହସ୍ତାନ୍ତର କରାଯାଇଥାଏ
- ଉଭୟ ପୁରୁଷ ଓ ମହିଳା ଅଂଶଗ୍ରହଣ କରନ୍ତି
- ଗୋଟିଏ ଶାଢ଼ୀରେ **୫୦ ରୁ ଅଧିକ ଘଣ୍ଟା** ପରିଶ୍ରମ ଲାଗିଥାଏ

## କେଉଁଠାରୁ କିଣିବେ

⚠️ ଅସଲିୟତ ନିଶ୍ଚିତ କରିବାକୁ ସର୍ବଦା **ଜିଆଇ ଟ୍ୟାଗ୍ (GI tag)** କିମ୍ବା **ବୟନିକା ପ୍ରମାଣପତ୍ର** ଖୋଜନ୍ତୁ। ହସ୍ତତନ୍ତର ସୁରକ୍ଷା ପାଇଁ ସର୍ବଦା ଅସଲି ଉତ୍ପାଦ କିଣନ୍ତୁ।
