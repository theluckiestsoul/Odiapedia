## Phase 2 Objective

> Start publishing real content and make Odiapedia discoverable via search.

No infra. No Terraform yet.
Only **content + MDX + SEO**.

---

## Phase 2 Deliverables (Very Clear)

By the end of Phase 2:

* MDX rendering is wired
* At least **5–7 high-quality articles live**
* Google can index your pages
* You have a repeatable writing workflow

---

## Phase 2 – Action Items

### 1️⃣ Add MDX Support

* [ ] Install MDX dependencies
* [ ] Read `.mdx` files from `/content`
* [ ] Render articles using App Router
* [ ] Generate routes dynamically

**Outcome:**
One `.mdx` file = one webpage

---

### 2️⃣ Define Article Template (Standardize Early)

Every article must have:

* Title
* Description
* Category
* Headings (`h2`, `h3`)
* Internal links

This avoids messy content later.

---

### 3️⃣ Publish First 5 Articles (Must-do)

**Recommended starter set**

1. What is Odiapedia
2. What is Raja Parba
3. Common Odia greetings
4. History of Odisha in brief
5. Famous foods of Odisha

Do not overthink. Publish, then refine.

---

### 4️⃣ Basic SEO Wiring

* [ ] Metadata from MDX frontmatter
* [ ] Clean URLs
* [ ] `<title>` and `<meta description>`
* [ ] Internal links between articles

---

### 5️⃣ Google Indexing

* [ ] Add site to Google Search Console
* [ ] Submit sitemap
* [ ] Verify indexing

This is when traffic *starts*.
