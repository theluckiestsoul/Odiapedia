# Odisha drill-down map data

Generated by `scripts/build-map-drilldown.py`. Coordinates are in the /map SVG space (the units of
`src/data/odisha-map.json` multiplied by 100).

* `<district>.json` — block and census sub-district shapes, derived from village boundaries
* `<district>-villages.json` — simplified village boundaries joined to Local Government Directory codes

Village boundaries: DataMeet, Indian Village Boundaries (Census 2011), © DataMeet contributors,
https://github.com/datameet/indian_village_boundaries — licensed under the Open Database License (ODbL) 1.0.
These derived files are made available under the ODbL 1.0 as well: https://opendatacommons.org/licenses/odbl/1-0/

District outlines: DataMeet, Districts of India (Census 2011), CC BY 2.5 India.
Block, gram panchayat, sub-district and village names/codes: Local Government Directory, Government of India (Dec 2022).
